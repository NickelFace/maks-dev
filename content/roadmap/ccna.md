<div class="rdm-section-label">Key exam topics</div>
<div class="tips-grid">
<div class="tips-header"><div>Topic</div><div>What you must nail</div></div>
<div class="tip-row"><div class="tip-cell">Subnetting</div><div class="tip-cell">Compute fast: host counts, network address, broadcast. VLSM without a calculator.</div></div>
<div class="tip-row"><div class="tip-cell">STP root bridge</div><div class="tip-cell">Elected by lowest Bridge ID (priority + MAC). Portfast only on access ports.</div></div>
<div class="tip-row"><div class="tip-cell">OSPF DR/BDR</div><div class="tip-cell">Elected by highest router-id / highest loopback / highest interface IP. Broadcast vs P2P.</div></div>
<div class="tip-row"><div class="tip-cell">ACL rule order</div><div class="tip-cell">First match wins. Implicit deny at the end. Standard ACL goes near the destination.</div></div>
<div class="tip-row"><div class="tip-cell">NAT PAT</div><div class="tip-cell">ip nat inside/outside on interfaces. overload = PAT. Verify with show ip nat translations.</div></div>
<div class="tip-row"><div class="tip-cell">HSRP vs VRRP</div><div class="tip-cell">HSRP: Cisco proprietary, active/standby. VRRP: open standard, master/backup. GLBP: load-balancing.</div></div>
<div class="tip-row"><div class="tip-cell">802.1Q vs ISL</div><div class="tip-cell">802.1Q: standard, 4-byte tag, native VLAN is untagged. ISL: legacy Cisco encapsulation.</div></div>
<div class="tip-row"><div class="tip-cell">WPA2 vs WPA3</div><div class="tip-cell">WPA3: SAE instead of PSK, required for Wi-Fi 6. WPA2: AES/CCMP. WEP = broken, don't use.</div></div>
